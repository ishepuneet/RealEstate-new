# Haven Realty — Vite + React + Tailwind

Luxury real-estate landing page recreated from the supplied reference image.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Stack

- Vite
- React
- Tailwind CSS v4
- Responsive CSS
- No icon library required

## Notes

The property photos are loaded from Unsplash URLs so the project stays lightweight. Replace those URLs with your own Jalandhar/India property photos before delivering the site to a client.
